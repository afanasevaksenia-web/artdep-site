# СМЕНА

Мобильный штаб площадки для съёмочной группы. Демо: сериал «Община», смена 53, 10.07.2026.

Стек: React 19, TanStack Router, Zustand, Tailwind v4, Vite. Данные — клиентские сиды (`src/lib`), без бэкенда.

## Экраны

Сегодня · Площадка (табель) · Чаты · Доска дня · Ещё (группа, меню, примечания, КПП, сценарий, объекты, проекты)

## Разработка

```
npm install
npm run dev
```

## Сборка

```
npm run build
```

Деплой на GitHub Pages выполняется автоматически из `main` (см. `.github/workflows/pages.yml`).
