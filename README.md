# Платформа для съёмочных групп

Мобильное веб-приложение (PWA) для киногрупп: проекты, приглашения по
ссылке, КПП, вызывной, чаты, файлы, транспорт. Подробное задание и статус
по этапам — в [`CLAUDE.md`](./CLAUDE.md).

Первый тестовый проект на платформе — сериал «ОБЩИНА»; сама платформа не
привязана ни к одному конкретному сериалу.

## Стек

Vite + React + TypeScript, Supabase (auth/db/storage/realtime), TanStack
Query, React Router, SheetJS (импорт КПП из Excel).

## Разработка

```bash
npm install
npm run dev
```

Переменные окружения (`.env`) уже содержат публичный (publishable) ключ
Supabase — он безопасен на фронтенде, все права проверяются в базе через
RLS. Сервисный ключ никогда сюда не кладите.

## База данных

Схема — в `supabase/migrations/`. Применена к проекту `obshina-crew`
(`qnuysxrhoaguhyvtxgls`, eu-central-1). Новые изменения — отдельной
миграцией, существующие не переписываем.

## Статус

Этап 1 («Основа», см. CLAUDE.md, раздел 10) — в работе: вход, проекты,
приглашения, группа, КПП, вызывной с таймингом, импорт КПП из Excel с
сопоставлением колонок. Чаты, файлы, табло, транспорт и офлайн — следующие
этапы.
